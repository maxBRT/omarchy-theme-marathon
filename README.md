# Marathon

A dark Omarchy theme with a near-black background, acid-green accent, and a small selection of Marathon-inspired wallpapers.

## Install

```bash
omarchy theme install https://github.com/maxBRT/omarchy-theme-marathon
omarchy theme set Marathon
```

## Included wallpapers
